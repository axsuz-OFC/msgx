# MsGX - Feature Messaging Web App

A modern WhatsApp-style messaging web application built with pure HTML, CSS, and JavaScript. No backend required. Works offline as a PWA.

## 🌟 Features

- 💬 Modern Chat UI (WhatsApp-style)
- 📸 Status Updates (Text, Image, Video)
- 📞 Voice & Video Call UI
- 📢 Broadcast Lists
- ⭐ Starred Messages
- 🔗 Linked Devices
- 🎨 Custom Wallpaper (Image/Video)
- 🌈 RGB Messages Animation
- ✍️ Text Formatting (*bold*, _italic_, ~strike~, `code`)
- 🔒 User Authentication (LocalStorage)
- 📱 PWA Support (Installable)
- 🌙 Dark Theme with Purple + Blue Gradient
- 📎 Attach Files (Images, Videos, Audio, Documents, Polls, Contacts)
- 🎤 Voice Recording
- 😀 Emoji Picker
- 🔍 Search Messages & Contacts
- 👤 Profile Edit
- ⚙️ Settings (Account, Privacy, Notifications, Storage, Help)
